    ¿Qué guarda el código QR?
    Déjalo vacío para usar la web de siempre. Cuando cambies datos, descarga inventario.json («Copia de seguridad») y vuelve a publicarlo: las etiquetas ya impresas siguen sirviendo.

    Cómo imprimir en la Brother QL-800
    1. Elige arriba el mismo rollo que tiene puesto la impresora.
    2. Marca en la lista las etiquetas que quieras (o deja solo la que tienes abierta) y pulsa Imprimir.
    3. En la ventana de impresión de Chrome o Edge: impresora Brother QL-800 · Márgenes Ninguno (Ränder: Keine) · Escala Predeterminada / 100 % · desactiva Encabezados y pies de página (Kopf- und Fusszeilen).
    4. Si sale cortada o en dos trozos: en Windows, Impresoras → Brother QL-800 → Preferencias de impresión, elige el mismo tamaño de papel. Si sale girada:
    5. ¿Prefieres P-touch Editor? «Descargar PNG» crea la imagen a 300 ppp y tamaño real para insertarla. O conecta el CSV exportado como base de datos: la columna QR ya trae el contenido del código.
